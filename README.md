## 🧠 Architecture & System Design

I specialize in moving beyond monolithic structures, actively applying advanced architectural patterns to ensure high availability and clean boundaries:

*   **Architectural Styles:** Microservices Architecture, Hexagonal Architecture (Ports & Adapters), Domain-Driven Design (DDD).
*   **Distributed Patterns:** Event-Driven Systems, CQRS (Command Query Responsibility Segregation), Event Sourcing, Saga Pattern for distributed transactions.
*   **Security & Identity:** Backend-for-Frontend (BFF) pattern, API Gateways, OAuth2 & OIDC, JWT Authentication, Keycloak IAM.
